The apps

iOS and macOS, both unsigned. That is a deliberate trade-off: a few extra taps on first install, and no account anywhere.

iOS and iPadOS

  1. Install AltStore or SideStore following their setup for your device.
  2. Add this source in the app: 
    https://github.com/macblizzard/hermey/releases/latest/download/altstore.json
    It is a release asset on purpose: the latest release always serves the newest build, with no host of our own in the loop.
  3. Install Hermey from the source.

Any signing tool that accepts an unsigned IPA works (Sideloadly, Feather, or Xcode with a free Apple ID).

A free Apple ID signs for about seven days. Then the app stops launching until it is re-signed. AltStore and SideStore re-sign in the background while you are on the same network as their server; a paid developer account extends that to a year. The app itself needs no account.

macOS

  1. Download the disk image from macblizzard.github.io/hermey-downloads — a direct link, with no release-CDN redirect in front of it. The newest build is published as Hermey-macOS-<version>.dmg, so the filename tells you which build you have. Open the image and drag Hermey onto the Applications shortcut.
  2. The build is unsigned, so macOS quarantines it once. Either right-click → Open → Open, or run: 
    xattr -dr com.apple.quarantine /Applications/Hermey.app
    macOS remembers the choice. Moving or re-downloading the app brings the mark back with the new copy.
  3. Pair the same way as the phone: run hermey pair on the host and paste the code or the whole link into Pairing code or link — the Mac has no camera. A hand-issued device token still works under Advanced.

macOS 14 or later is required.

First run

  • Add a server: paste https://<host>.<tailnet>.ts.net:8443 or scan the QR.
  • Enter the code from hermey pair.
  • The bot list is the home screen. Tap a bot for its endless conversation; the room list is behind the three-dot menu.

Notifications and badges

A bot's reply earns a notification when that bot is not the one on screen — a chat you are reading has already told you. Both apps put the total waiting on the Dock tile or the app icon.

PlatformHow it behaves
macOSDelivers a banner as soon as the host reports the reply, even in the background; clicking it opens that conversation.
iOS, app openDelivers while the app is running.
iOS, app closedFalls back to a background refresh iOS schedules — expect delays in the tens of minutes, and only while the phone is awake.

The relay closes that gap, and it is the only way a sideloaded build can. Push needs a credential for the team that signed the app, which a personal install does not have — so the host posts the banner to an app that already holds one. Install Bark (free), copy the address it shows, and paste it into Settings → Replies (iOS) or Settings → Notifications (macOS). Send a test proves it.

Settings has one switch and a per-bot quiet list. A quieted bot still counts on its row and in the badge; it just never buzzes. Reactions, drafts, pins and the switch are per-device; unread counts come from the host and survive a reinstall.

Unpairing and revocation

Removing a device in the app deletes its key. Revoking from the host closes that device's link immediately and refuses the next connection — the token it held is spent. Neither touches your bots, your profiles or anything else on the host.
