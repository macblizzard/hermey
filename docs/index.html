Hermey documentation

A native iOS and macOS client for a Hermes agent you run yourself — and the one command that installs the host it talks to.

Hermey is two pieces that meet at a tailnet address. hermeyd, one Rust binary, runs on the machine that already runs Hermes. The apps on your phone and Mac talk to it over HTTPS with a real certificate, and nothing else is in the path — no account, no relay, no service of ours.

Get started From nothing to a paired app — four steps, about five minutes after Hermes is up.

Quick start

Three steps. The first needs root on the Hermes host; the others happen on the device.

  1. Install the host. One command, safe to re-run as an upgrade. 
    curl -fsSL https://github.com/macblizzard/hermey/releases/latest/download/install.sh | sudo sh
  2. Pair a device on that host, with the phone in your hand — codes expire. 
    sudo hermeyd pair
    It prints a six-digit code, a https://<host>/?code=… URL and a QR the app can scan.
  3. Install the app and paste the code. iOS through AltStore or SideStore, macOS from the disk image. Both are unsigned — that is the stated trade-off.

Requirements

PieceNeeds
HostLinux with systemd or macOS with launchd, sudo (it writes under /opt, /etc and /var/lib), and a working hermes install with an engine home. Tailscale is optional but recommended — without it the service is reachable only from the host itself
iPhone / iPadiOS 17 or later, plus AltStore, SideStore or another signer
MacmacOS 14 or later

The two halves

Where it runsWhat it is
Host servicehermeyd on 127.0.0.1:8788, with the browser channel on 8790Rust service that adapts the Hermes engine to the apps' protocol. It holds the device registry, mints single-use 30-second tickets, relays the engine's WebSocket, and issues the local bearer at /var/lib/hermeyd/local.token that host-side scripts send.
AppsiPhone, iPad, MacSwiftUI clients. They hold a device key, never a host secret, and can only answer the questions the agent asks.
Front doortailscale serve --bg http://127.0.0.1:8788Terminates TLS with a real certificate at serve-root, so pairing URLs carry no port. It is the only front door: hermeyd refuses any bind but loopback, and the apps refuse a self-signed certificate.
