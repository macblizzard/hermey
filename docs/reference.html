Reference

The facts a script, an agent or a tired human needs: commands, ports, paths and URLs.

CLI

CommandWhat it does
hermey statusunit, port and health at a glance
hermey pairmints a code, a hermes:// link and a QR when possible
hermey logs [n]the bridge journal, newest last
hermey doctorunit, loopback health, gateway URL, Tailscale state, HTTPS through the certificate
hermey updatereinstall from the configured ref
hermey uninstallremove units and the serve mapping, keep state
hermey computer …observe / act / files / browser against a paired Mac

Ports and units

Bridge127.0.0.1:8787 — loopback only, by design
Tailnet:8443 via tailscale serve, real certificate
Unitshermey-bridge.service; hermey-gateway.service only when the host had no dashboard
Nevera unit named hermes-gateway.service — that is Hermes' messaging gateway

Paths

PathWhat
/opt/hermey/venvthe installed bridge
/var/lib/hermey/bridge.dbdevices, tickets, attachment index
/var/lib/hermey/room-attachments/uploaded files
/etc/hermey/gateway.envgateway token, 0600
/etc/hermey/providers.envoptional voice provider keys, 0600
~/Library/Application Support/Hermey/Computer/Workspace/the Mac's shared workspace for computer use

How updates arrive

  • Host: re-run the install command; it is an upgrade and keeps state.
  • macOS: Sparkle reads an appcast and offers the new build in the app.
  • iOS: the sideloading app refreshes from the AltStore source.
